# Proyecto Autobiografía - Katherine Murcia

## Descripción del Proyecto

Sitio web personal que presenta la autobiografía de Katherine Murcia, estudiante de IV semestre de Ingeniería de Sistemas de la Universidad El Bosque. El proyecto fue desarrollado como parte de la asignatura **Programación II** bajo la dirección del profesor Juan Camilo Hernández.

Este sitio contiene información personal, hobbies deportivos, formación académica e intereses profesionales, presentados de manera estructurada y con un diseño amigable.

## Tecnologías Utilizadas

### Frontend
- **HTML5**: Estructura semántica del documento con etiquetas modernas (header, nav, main, article, section, figure, etc.)
- **CSS3**: Estilos avanzados incluyendo:
  - Flexbox para diseño responsivo
  - Transiciones y efectos hover
  - Border-radius para esquinas redondeadas
  - Paleta de colores Material Design (Brown)

## Estructura del Proyecto

```
AUTOBIOGRAFIA/
├── index.html          # Página principal del sitio
├── Archivos/           # Recursos multimedia
│   ├── mtb.jpg        # Imagen - Mountain Bike
│   ├── trekking.jpg   # Imagen - Trekking
│   └── gym.jpg        # Imagen - Gimnasio
└── Styles/
    └── style.css      # Estilos CSS globales
```

## Características Principales

### Secciones del Contenido
1. **Sobre mí**: Información personal y formación regional
2. **Mis gustos deportivos**: 
   - MTB (Mountain Bike)
   - Trekking y Senderismo
   - Gimnasio
3. **Formación académica**: Detalles de estudios actuales
4. **Intereses**: Áreas de interés profesional
5. **Datos curiosos**: Información adicional personal

### Componentes de Diseño
- **Header**: Título principal con navegación horizontal
- **Navegación**: Menú de enlaces internos para acceso rápido a secciones
- **Imágenes con figcaption**: Elementos visuales con descripciones
- **Efectos interactivos**: Hover en imágenes y enlaces
- **Diseño responsivo**: Adaptable a diferentes tamaños de pantalla

## Paleta de Colores

Se utiliza la paleta **Material Design - Brown**:
- Fondo principal: `#efebe9`
- Header: `#5d4037`
- Texto: `#3e2723`
- Acentos: `#6d4c41`, `#795548`, `#bcaaa4`

## Instrucciones de Uso

1. Abrir el archivo `AUTOBIOGRAFIA/index.html` en un navegador web
2. Navegar usando los enlaces del menú principal
3. Explorar las diferentes secciones de la autobiografía

## Compatibilidad

El proyecto es compatible con navegadores modernos que soporten:
- HTML5
- CSS3 (Flexbox, Transiciones)
- Visualización de imágenes JPEG
