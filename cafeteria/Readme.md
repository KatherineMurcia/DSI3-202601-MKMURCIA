# El Café de mi Tierrita
## Descripción Técnica

Landing page desarrollada bajo arquitectura frontend básica utilizando HTML5, CSS3 y JavaScript, aplicando principios de estructuración semántica y metodología BEM (Block Element Modifier) para organización modular de estilos.

El proyecto implementa separación de responsabilidades entre estructura (HTML), presentación (CSS) y comportamiento (JS), garantizando escalabilidad, mantenibilidad y legibilidad del código.

## Arquitectura del Proyecto
```
CAFETERIA/
├── index.html        # Estructura del documento
├── css/
│   └── styles.css    # Estilos organizados con BEM y variables CSS
├── js/
│   └── script.js     # Lógica de interacción (carrusel)
└── img/              # Recursos gráficos
```

## Principios Aplicados

1️⃣ Estructura Semántica: Uso de etiquetas HTML5

2️⃣ Metodología BEM: Organización de clases bajo el patrón

3️⃣ CSS Avanzado

4️⃣ JavaScript: Implementación de carrusel horizontal 


## Objetivo Académico

Aplicar conceptos fundamentales de:

- Maquetación profesional
- Organización estructurada del CSS
- Separación de responsabilidades
- Implementación de componentes reutilizables
- Interacción básica sin frameworks
